# 📊 Power BI Learning & Projects Repository

This repository contains my structured learning materials and hands-on projects using **Microsoft Power BI**.  
It covers core concepts like data visualization, Power Query, DAX, data modeling, and a complete sales data analysis project.

The goal of this repo is to document my learning journey and showcase practical implementations of Power BI concepts.
