## 🎯 Project Overview

The Sales Data Analysis report helps understand:

- Sales performance  
- Profit trends  
- Customer and product behavior  
- Discount impact  
- Time-based analysis  

Using Power BI, raw data is cleaned, modeled, and visualized to support better business decision-making through interactive pages and filters.

---

## 📥 1. Bringing the Data to Power BI Desktop

- Imported datasets into Power BI Desktop.  
- Verified and corrected data types and formats.  
- Ensured consistency across fields such as dates, sales, profit, discounts, and quantity sold.  

---

## 🔄 2. Data Transformation

Performed data cleaning and transformation using **Power Query Editor**:

- Removed duplicates and handled null values.  
- Renamed columns for clarity.  
- Changed data types.  
- Created calculated columns (e.g., Profit).  
- Split and merged columns where needed.  
- Standardized categorical fields (City, Product, Customer, Promotion, etc.).  

This step prepares clean and reliable data for analysis.

---

## 🧩 3. Data Model Overview

- Built relationships between fact and dimension tables.  
- Defined primary and foreign keys.  
- Set cardinality and cross-filter directions.  
- Designed a star-schema style model.  
- Optimized the model for correct aggregation and filtering behavior.  

The data model ensures accurate slicing and interaction across report pages.

---

## ❓ 4. Business Questions Answered

The report is designed to answer the following:

1. **Top / Bottom 5 products** by:
   - Sales  
   - Profit  
   - Quantity Sold  

2. **Sales trends over time**:
   - Daily  
   - Monthly  
   - Quarterly  
   - Annually  

3. **Relationship between Sales and Profit** using comparative scatter visuals.

4. **Average discount offered** across promotion categories.

5. **Sales by city and region** using map and bar visuals.

6. **Total number of orders** for selected periods.

7. **Comparison of Sales / Profit / Quantity Sold** between two user-selected time periods.

8. **Detailed order-level analysis** displaying:
   - Sales  
   - Profit  
   - Discount  
   - Net Sales  
   - Units Sold  
   - Price per Unit  

   With interactive filters for:
   - Product  
   - Date  
   - Customer  
   - Promotion
